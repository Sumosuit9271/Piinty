# Piinty social videos — screen demo clips

Three vertical (9:16) clips, ready to post to Instagram Reels and TikTok, made from real recordings of the app with punchy captions on top. No changes to the app itself.

## The three clips

1. **"Make a group in 10 seconds"** (~12s)
   Hook: "Your mates owe you pints. Time to keep score."
   Shows: sign in, create group, invite link share.

2. **"Add a pint with the receipts"** (~14s)
   Hook: "He said next round's on him. It wasn't."
   Shows: tapping a cell, + Pint, adding a note, the number ticking up.

3. **"Settle up"** (~12s)
   Hook: "One tap and the debt's gone."
   Shows: opening pint history, filling in the circle, the leaderboard flipping — Pint Pappy and Roundling.

Each clip ends on the Piinty logo with the line "Keep track of owed pints between mates!"

## Look and feel

Matches the app: cream background, amber accents, rounded chunky captions, bouncy playful motion. Big text that reads with the sound off, since most people watch muted. Phone-shaped frame around the recording so it feels native to the feed.

## How I'll make them

- Record the real app on a phone-sized screen using a demo group with the sample mates, so no real people's names or photos appear.
- Compose each recording in a video project (Remotion) at 1080x1920, 30fps, with animated captions, a logo intro sting and end card.
- Render each clip to an MP4 you can download and post.

## Also included

- Caption text and hashtag sets for each clip, for both Instagram and TikTok.
- A suggested posting order and cadence.

## Technical notes

- New `remotion/` directory in the project holding the video source, so clips can be re-rendered or tweaked later.
- Screen capture via Playwright against the local preview at a 390x844 viewport, seeded with locally-created sample mates only.
- Output MP4s written to the documents folder for download; app code untouched.

Nothing to start — I'll use sample mates for the on-screen names. If you'd rather see specific mate names or a specific group name in the videos, tell me and I'll use those.
